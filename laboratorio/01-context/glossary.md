# Glosario de términos

> Estado: 🟢 Estable | Última actualización: 2026-06-24
> Autor: Equipo ADSO 3145555 | Equipo: Producto / Dominio

Este glosario define los términos clave utilizados en el dominio del SENA y en el sistema **Horarios SENA**. Los términos están ordenados alfabéticamente.

---

| Término | Definición | Contexto |
|---------|------------|----------|
| **Ambiente de aprendizaje** | Espacio físico o virtual donde se desarrolla el proceso de formación. Puede ser un aula, laboratorio, taller, sala de sistemas, etc. | SENA / Infraestructura |
| **Aprendiz** | Persona que recibe formación profesional integral en el SENA. Está matriculado en una ficha. | SENA / Actores |
| **Competencia** | Capacidad técnica o transversal que el aprendiz debe desarrollar durante la formación. Tiene un código oficial SENA y horas asignadas. | SENA / Académico |
| **Coordinador Académico** | Persona encargada de planificar, organizar y supervisar los procesos formativos en un centro de formación. | SENA / Actores |
| **Ficha** | Grupo de aprendices que cursan un mismo programa de formación en una misma jornada y centro. Tiene un código único. | SENA / Académico |
| **Formación Profesional Integral (FPI)** | Modelo educativo del SENA que busca desarrollar el saber, saber hacer, saber ser y saber convivir. | SENA / Pedagógico |
| **Franja horaria** | Bloque de tiempo definido por día, hora de inicio y hora de fin. Se utiliza para programar sesiones de formación. | Sistema / Horarios |
| **Horario** | Asignación de un instructor, ambiente, ficha y franja horaria para una sesión de formación. | Sistema / Core |
| **Instructor** | Persona que orienta el proceso de formación. Puede ser de planta (funcionario público) o contratista. | SENA / Actores |
| **Jornada académica** | Período del día en que se imparte formación. Ejemplos: Mañana (6:00-13:00), Tarde (13:00-18:00), Noche (18:00-22:00). | SENA / Catálogos |
| **Línea Tecnológica** | Nivel más alto de la jerarquía de conocimiento del SENA. Agrupa grandes áreas del saber (ej. Tecnologías de la Información). | SENA / Académico |
| **Microservicio** | Unidad autónoma y desplegable que implementa un subdominio del sistema. Cada microservicio tiene su propia base de datos. | Sistema / Arquitectura |
| **Modalidad de formación** | Forma en que se ofrece un programa: Presencial, Virtual, A Distancia o Mixta. | SENA / Catálogos |
| **Observación** | Registro de novedades, conflictos o bloqueos asociados a un horario. Puede tener severidad (Info, Warning, Critical). | Sistema / Horarios |
| **Programa de formación** | Oferta educativa del SENA, con un código oficial, nombre, nivel (Técnico, Tecnólogo, Especialización, etc.) y diseño curricular aprobado. | SENA / Académico |
| **RAP (Resultado de Aprendizaje)** | Logro medible que el aprendiz debe demostrar al finalizar una competencia. Se escribe en infinitivo (ej. "Construir servicios de ML"). | SENA / Académico |
| **Red de Conocimiento** | Agrupación disciplinar dentro de una Red Tecnológica. Agrupa programas con fundamento curricular común. | SENA / Académico |
| **Red Tecnológica** | Agrupación técnica intermedia dentro de una Línea Tecnológica. | SENA / Académico |
| **Sede** | Unidad institucional física del SENA donde se imparte formación. Puede ser un edificio, una tecnoacademia o un tecnoparque. | SENA / Estructura |
| **SENA** | Servicio Nacional de Aprendizaje. Entidad pública colombiana encargada de la formación profesional integral. | SENA / Institucional |
| **SOFIA Plus** | Sistema de gestión académica oficial del SENA. Administra matrículas, certificaciones y oferta académica. El sistema Horarios SENA no lo reemplaza, solo se integra con él. | SENA / Sistema oficial |
| **Tecnoacademia** | Espacio de formación en ciencia y tecnología para jóvenes de educación básica y media. | SENA / Estructura |
| **Tecnoparque** | Programa de innovación tecnológica del SENA que actúa como acelerador de proyectos I+D+i. | SENA / Estructura |
| **Tipo de formación** | Clasificación de los programas según el certificado que otorgan: Titulada, Complementaria, Especialización Tecnológica, etc. | SENA / Catálogos |
